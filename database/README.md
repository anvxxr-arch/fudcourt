# database/ — canonical schema ownership

> Moved here from `apps/web/db/` (Phase 2 of the domain restructure, 2026-10-01)
> so that **database ownership does not belong to Next.js**. DDL semantics were
> not changed by the move. Table-ownership map is maintained here; column-level
> documentation stays in `docs/architecture/SCHEMA.md`.

## Contents

| File | What it is | Generator / gate |
|---|---|---|
| `schema/schema.sql` | Turso (libsql) schema dump — **system of record for the treasury family** (DR-019) | generated by `apps/web/scripts/tools/dump-schema.mjs`; drift gate `--check` must return `SCHEMA_OK` |
| `schema/pg-schema.sql` | local Postgres (TimescaleDB) **read model** mirror of `schema.sql` (`public` schema; `asset_history`/`price_history` are Timescale hypertables) | projected by `apps/web/src/platform/db/mirror.ts` via `scripts/tools/pg-load.ts`; must mirror `schema.sql` 1:1 |
| `schema/executor-schema.sql` | the `executor` Postgres schema (live trading data) — tracked readable copy of the DDL embedded in `apps/web/src/platform/executor/store.ts` | byte-identity (normalized) asserted by `executor-store-tests.ts`; applied idempotently at startup by `ensureExecutorSchema()` (DR-020) |

## Migration policy (evidence-based, per store)

There is deliberately **no cross-store migration runner** (DR-020, objective
§57 "do not introduce a new migration framework unnecessarily"):

- `executor.*`: idempotent `CREATE … IF NOT EXISTS` DDL, one tracked copy +
  one embedded copy, drift-pinned by test. Forward-only; a column removal is a
  manual operation.
- Turso treasury: schema is the live dump; changes are made in Turso and
  re-dumped (drift gate keeps the repo honest).
- Neon (Payload CMS): Payload's own migration folder
  (`apps/web/src/cms/migrations/`) stays with the CMS by Payload convention.

If a future change outgrows this (multi-writer stores, ordered data
transforms), introduce ordered `database/migrations/NNNNNN_*.sql` then — not
before.

## Table ownership

One owner domain per table. "Owner" = the domain whose code writes it; readers
may exist elsewhere per the dependency rules.

### Neon (Payload CMS, `apps/web/src/cms/migrations/`)

Owned by the CMS (content: posts, media, users for the blog). Not part of this
map's trading/financial surface.

## Invariants enforced at the DB level (not just app code)

- unique execution id (PK), unique `event_id`, unique
  `(execution_id, client_order_id)`, unique `(account_id, exchange_trade_id)`
- `user_id` scoping on every executor query (wrong user ⇒ `null`/`[]`, API 404)
- executor objects live **only** in the `executor` schema — the Turso→Postgres
  mirror prunes `public` wholesale and must never touch executor data (DR-020)
- timestamps are `bigint` unix **milliseconds** (exact JS round-trip);
  money/quantity are `double precision` with `decimal.js` upstream in risk/sizing
